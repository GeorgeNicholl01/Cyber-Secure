Cyber Secure is a browser-based cybersecurity awareness training platform focused on addressing human-factor security risks within organisations. It delivers clear, practical guidance for non-technical users through structured, accessible learning modules.

## Features
- Modular cybersecurity awareness content (phishing, passwords, data handling, updates, burnout)
- Human-factor focused explanations of real-world cyber threats
- Clean, accessible and distraction-free user interface
- Responsive design for desktop and mobile devices
- Static architecture for portability and reduced attack surface
- Demonstration login page illustrating future system expansion

## Tech Stack
- HTML5
- CSS3
- JavaScript (minimal usage)
- Static multi-page web architecture

## Running Locally
1. Clone or download the repository
2. Open the project folder
3. Launch `index.html` in a modern browser  
   *(or deploy using any static hosting provider)*
